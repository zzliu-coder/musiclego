# 桌面视觉检查

检查对象是本轮实际构建的截图；所有截图由 `verify-visual.mjs` 重新产生。入场动画完成后取图，避免把淡入中间帧误当作透明度缺陷。

## 逐页观察

- 乐句编辑：工作表面保持中性；角色颜色只用于声音和音符；时间轴、音符边界清楚。音轨列表与编排列表允许区域内滚动。
- 全曲编排：独立 / 共享标志、时间尺和轨道行对齐；桌面保留下方当前片段编辑。
- 音色：音色列表、当前音色和效果控制有明确分区；内容可在区域内滚动。
- 演奏处理：处理链说明和“展开为音符”的作用范围可见；移调、琶音、Swing 属于实际音乐处理。
- 混音：各轨混音和总输出分开；颜色沿用声部；全曲导出入口可见。
- 模板：筛选、搜索、卡片信息和配套模板入口清楚；没有新增流程解锁。
- 创作辅助：输入与保留条件分组；候选出现后滚动到比较区域；内容长于视口时弹窗内部滚动。
- 我的作品：保存状态、另存、下载、恢复点及作品列表均可见；当前作品删除按钮禁用并说明先切换。
- 组件页：变体、选中、禁用、忙碌、图标、字段、开关、候选栏使用生产实现。清理了旧通用按钮覆盖与组件页残留的紫色滑条。

自动几何检查覆盖 1280 / 1440 和清白 / 暖白两种主题。人工逐页观察的具体截图列表记录在 `evidence/visual-review.json`。小屏 / 触屏专项按用户要求延期；之前的小屏诊断截图不计入本轮验收。

长时间回归开始后只发生了通用控件 CSS 收敛。`runtime-equivalence.json` 比较长测 HTML 与最终 HTML，证明全部脚本和非 CSS 结构逐字一致；最终 CSS 另经桌面视觉及实际指针检查。
