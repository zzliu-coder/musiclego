# 1.6 工程候选版

这一版把配套模板、和弦说明、规则生成和多作品保存接入现有乐构工作台。原有画笔、编排、音色、混音与普通音符编辑继续可用。

## 使用路径

1. 点击「模板」→「配套模板」，选择一种风格，预听后应用。
2. 选中新添的「我的旋律」片段，打开「创作辅助」，选择参考和弦并生成候选。
3. 选择喜欢的候选应用；需要固定某些音符时，先在画布选择，再打开辅助面板保存保留项。
4. 选择鼓轨 / 贝斯轨使用对应生成策略；发展编排或建议混音前都可以预听。
5. 顶部文件夹切换作品；导出菜单下载工程、MIDI 或 WAV。

## 迁移和保留

工程格式升级为 v3，保留普通音符和音色快照，新增和声、保留项和生成来源。旧 IndexedDB autosave 迁移一次，原存储记录保留。旧项目文件可以直接打开；同编号再次导入会成为独立副本。

## 验收界限

当前工程自动检查见 `evidence/verification.json`，长测见 `evidence/soak.json`，87 项逐项状态见 `acceptance.json`。没有通过的项目保留原状态；不以历史版本的 PASS 代替当前结果。

8 套配方已经实际渲染成 WAV 并检查信号、非法值和削波。人工音乐听感评审尚未进行，当前不标为“已精选”。声卡延迟和物理设备体验未测。小屏体验按用户最新决定留到后续专题。
