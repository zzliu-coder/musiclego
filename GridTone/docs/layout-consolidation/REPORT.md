# 工作界面整合

本轮沿用轻拟物材质，仅重整工作区信息层级与空间分配。保留工程版本、音符、音色定义、资源身份、操作目标和候选提交机制。未自动推送远端。

## 实现

- 品牌与作品名合成一个入口；作品、导出、全曲播放参数及设置收进锚定菜单。顶栏窄窗最多两组功能行。
- 基础编辑命令移入当前工作区，编排中与结构动作横向合并；放大画板仍只有一个命令目标。侧栏打开后按实际可用宽度换行。
- 轨头与坐标计算同步从 264 改为 216 像素；轨高 84，预览高度同步调整。
- 模板库将集合与用途放左侧，结果占中间，详情与固定试听/采用在右侧。窄窗分类和详情可独立返回；示例作品每首独立显示。
- 和弦进行使用宽浏览区；目标保持固定，参数可滚动，试听和放置固定于底部。
- 工具面板共用固定身份、滚动内容、固定主动作三段结构。生成、混音候选和原稿比较不因滚动丢失采用入口。
- 属性两列、块列表折叠；音符工具分为音高/时间/力度；演奏参数优先、写入与流程说明折叠。
- 本轨声音更换与试听同组；音色参数和包络并排；资源入口两列；不显示不适用的鼓/旋律音色类别。
- 混音保留 160 像素推子，效果折叠，主输出简化；混音候选使用逐轨对照表。
- 时间编辑区分作品长度与全轨时间段；移调按方式显露字段；和弦标注一行一项（窄窗两列）。
- 导出格式旁直接说明用途；作品维护折叠；帮助新增章节导航并去掉重复快捷键。
- “选择”改为“选音符”，“范围”改为“时间选区”，明确包含休止和全部音高；播放循环独立管理。
