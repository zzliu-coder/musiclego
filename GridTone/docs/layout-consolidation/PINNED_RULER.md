# 固定小节 / 拍标尺验收

日期：2026-09-20。范围：当前音符编辑器（旋律与鼓），不调整已确认的全局栏和局部工具栏。

## 实现

- `piano-roll.js`：时间尺独立 SVG 层，复用现有 28px 顶部高度与音符时间坐标；纵向固定，横向跟随音符。音高尺横向固定，左上角双向固定。
- 小节显示主编号，空间足够时显示“1.2、1.3、1.4”等拍编号；缩小时隐藏次级文字，保留拍刻度。分页沿用音乐块内小节编号。
- `editor-gestures.js`：标尺点击沿用编辑落点 / 播放定位；左上角和右键不触发音符编辑。
- `app.js`：标尺播放点与原播放头共用位置及显示条件。第一次停止保留位置，第二次停止回曲首，与既有行为一致。
- `template-shelf.js`：固定轴不接受模板放置；拖放投影位于固定轴下面；离开有效区域清除旧投影与缓存落点。
- WeakSet 按滚动节点去重监听，重新绘制 SVG 时继续绑定当前节点。
- 更新组件示例、设计系统与覆盖表。遵循 Impeccable 的紧凑与一致性要求，保持既有配色和层级。
