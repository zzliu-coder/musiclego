# 紧凑工作台单页样板

## 范围

仅编排及其下方单轨编辑器启用 compact-workbench。混音、放大编辑器、模板库、侧栏和其他页面维持原有布局，等待用户确认后再推广。现有脏工作区保留；未提交或推送 GitHub。

## 做法

- 编排结构操作移入顶部内容宽度托盘；当前对象与基础命令各有短托盘。
- 品牌不再吞掉所有剩余宽度；托盘按内容占宽，不强制等高大卡片。
- 单轨控制区共用 editor-control-deck。容器至少1360px时，按“短标题→绘音工具→网格/缩放→音色/试听/窗口操作”组成单行。较窄时按“标题＋绘音工具”“视图＋音色操作”分成两行，DOM阅读和键盘顺序保持一致；极窄窗口再按组换行。
- 内部材质为暖灰浅托盘、上沿轻高光，沿用系统色与控件规格。当前样板播放与停止统一44px，速度为44px高的底线输入；普通工具32px、图标36px，粗指针保留44px规则。
- 极窄窗口允许工作区纵向滚动，防止编排被下方编辑器吞没。
- 移入顶部的结构操作仍受和弦方案 composer 的 inert 边界保护。
- 原声音、音符、时间几何、撤销、工程格式和保存控制器不变。
