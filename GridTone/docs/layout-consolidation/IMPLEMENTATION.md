# 模块化工作界面实施记录

本轮：2026-09-19。主工程 GridTone；分支 codex/legou-tactile-2-2-1。未推送远端，未修改音乐 schema、内置音符或音源定义。

## 交付内容

- 编排上方独立为“编排结构 / 当前对象 / 基础编辑”三个浅托盘。容器变窄时整组换行，保留文字名称与作用对象。
- 品牌作为作品入口，播放、视图、作品操作在同一紧凑总控中分组。
- 编排与下方画板分别滚动；打开编辑器后画板留在当前视野。放大模式基础编辑区收为一行。
- 单轨画板：画笔工具、网格、时间缩放、实际可见音域分别成组。时间选区保留休止和全部音高语义。
- 属性 / 音色 / 演奏 / 编排工具 / 编辑工具 / 生成 / 和弦草稿都使用明确的头部、滚动内容、动作区域。生成、和弦不再由 DOM 选择器猜测并搬动按钮。
- 16 个既有弹窗调用的底部动作显式传入 actions。音色参数通过 slots 变体固定试听与完成。时间/移调业务事件回归应用控制器；焦点工具只负责焦点与弹窗。
- 模板库：分类、结果工具条、材料管理、试听与采用分组；其他放入方式下沉到明确的展开区；声音固定目标名保留。
- 混音保留 160px 推子；临时试听、静音、只听的归属保持。批量面板由实际顶底栏尺寸定位。
- 全曲调性与 Swing 在全局入口分组。修正 WAV 导出忙碌按钮选择器，以及单音频导入立即采用的说明。
- 生产组件样例、覆盖表、新增11条模块契约测试同步更新。旧调用与原始业务测试保留。
