## 已实现

- 编排、乐句、混音三个工作区共用音乐状态；常驻素材架和非模态创作停靠面板。
- 候选固定目标，参数改变即失效；局部补丁保留无关编辑，预听使用实际输出范围。
- 贝斯发声音域、鼓风格/力度、伴奏策略、跨界持续音、固定声部依赖顺序和一次性微时移处理。
- 节奏骨架、动机联系、回答、结尾、色彩连接与对应解释；输出保持普通可编辑音符。
- 统一素材放置、真实拖拽取消、长素材明确落点、共享实例隔离；实际歌曲长度显示正确。
- 保存失败保留草稿和恢复入口；录音取消/拒绝/迟到授权释放资源。
- 设计组件、排版和状态规则收敛；12种桌面状态完整计算样式对比通过。
