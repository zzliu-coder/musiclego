# 乐构 2.3.0：轻量控件与经典声音扩充

日期：2026-09-19。源基线：用户提供的 2.2.1 源码，提交 `494a515`。本轮在原工程内迭代，作品结构仍为 v3。

## 实现

- 数字输入、文本输入、搜索与原生选择框：透明底、单底线、无按钮投影；保留标签、箭头、文本光标、Tab 聚焦、错误和禁用状态。
- 画笔／选择／范围等工具共用浅底托盘；复制、撤销等普通操作无常驻框，禁用不会额外出现灰盒。播放、停止、M/S、音乐块保留浅厚度。使用 Impeccable polish 流程，用户确认的轻拟物方向优先。
- 新增 26 个旋律音色：10 个 VA、8 个四算子 FM、8 个 AKWF 周期波。包含 Mini 风格低音／主音、303 风格酸性低音、Juno 风格弦幕、DX 风格数字电钢、Reese、铜管、脉冲键、管钟等。
- 新增 1 套 16 件采样 808。开闭镲互斥只作用于此新增鼓组，保留旧鼓的渲染行为。
- 新增 24 个音乐模板：12 鼓点、7 伴奏、5 贝斯。覆盖 Disco、Electro、2-step、D&B、Trap、Boom-bap、One-drop、Dembow、Bossa、Afro、Tom fill、Funk，以及反拍、Charleston、Clave、琶音、Walking、Tumbao 等不同骨架。
- 和弦进行原有 24 种保持，新增 12 种，全部 36 种进入主模板库；含调式／借用、爵士替代、十二小节大调与小调蓝调。按用途后可继续选择细分类别。
- 试听不写原稿；采用走原提交／撤销通道。目标旧鼓组缺少拉丁鼓件时，明确提示使用模板 808 试听，避免隐式替换用户音色。

## 体积、来源与兼容边界

完整单文件 HTML 为 2,905,275 字节（约 2.9 MB），所有代码、预设和选用采样内嵌，正常构建及离线运行无需网络。波表使用最多 64 个谐波的系数，无需下载长录音；Web Audio PeriodicWave 负责带限振荡。808 选取 16 个短单击，原始采样与波表合计低于 1.3 MB。未声称首屏速度的跨设备基准。

原始文件、固定提交、授权和逐文件 SHA256 位于 `vendor/expansion/sources.json` 与各源目录。维护下载脚本为 `scripts/fetch-expansion-sources.mjs`，日常构建不调用网络下载。

- [TR-808 Fischer](https://github.com/tidalcycles/sounds-tr808-fischer)，固定提交 `85fbecf1bec32553395625ea659e2a56dfd7c0e1`，CC0；Michael Fischer 原采样。
- [AKWF FREE](https://github.com/KristofferKarlAxelEkstrand/AKWF-FREE)，固定提交 `8de90bf94376670947369e69de0af6b9fbd19286`，CC0；精选 8 个单周期波形。
- VA／FM 预设、节奏与新增和弦编配由本项目原创。Mini／303／Juno／DX 为风格参考，无商业设备原厂音色包、Seqtrak 转储、完整 AMY 运行时或 DX7 六算子等效承诺。
- 新增 `studio-wave` 音色需 2.3.0 或更新版本。所需采样与声音定义随作品保存；旧作品仍可导入。固定 C 调伴奏素材采用现有明确移调流程，不声称自动配合任意已有和声。
