# 桌面工作区滚动修复

编排和乐句上下两块超出窗口时，现在可通过中间工作区整体纵向滚动访问。顶部、底部状态栏与素材架保持原位，内部画布滚动到边界后可继续滚外层。

原因：legou.css 的 overflow:visible!important 覆盖了实际滚动容器；外层固定高度并裁切溢出。修复删除冲突声明，保留组件层的 overflow:auto；嵌套画布开放纵向滚动传递，并预留滚动条空间。

## 当前验证

- 旧构建实际滚轮检查失败，复现日志见 evidence/baseline-failure.txt。
- 修复后12组合通过：1440×900、1280×720、1152×600 × 编排/乐句 × 创作面板开/关。较小有效视口覆盖桌面缩放后可用空间，未声称模拟真实浏览器缩放。
- 检查滚到底、底部按钮可命中、固定栏位置、无整页横溢、渲染/换视图保留位置、画布边界向外层继续滚动和作品数据不变。
- 原生Safari中重新加载并实际滚动两个视图，底部试听可点击；182核心测试、现有交互与长时间轴回归通过。
- verify-workspace-scroll.mjs 已纳入标准 verify 入口。

本轮只修改布局滚动；不拓展小屏适配。旧全量验收、听感待评与旧ZIP仍对应原构建，保存在closure-v2及baseline-release-verification.json。当前构建身份见dist/manifest.json和本目录回执。
