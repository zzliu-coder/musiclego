# 乐构设计系统 2.0｜暖白磁贴

随乐构2.1.0生产实现。优先级固定为：准确与及时 → 清楚、舒心、协调 → 浅厚度与反馈。参考规格见 `docs/magnet-2.1/BLUEPRINT.md`，每项验收状态见 `docs/magnet-2.1/acceptance.json`。

## 01 工作台与范围

一个编排工作台、下方按需展开的音符编辑器，另有混音。左侧是少量本次材料，完整库用于较宽空间里的查找；右侧只有一个工具槽。现有音色、节奏、本地生成、键位和工程v3保留。不添加账号、发布、大模型、独立乐句导航、装饰封面或巨型播放器。

默认主题A“暖白磁贴”；已有 `crystal` 偏好迁移为A的显示。已有 `pearl` 为C“奶油浅瓷”，只改变中性底色与表面，不改变几何。B“清白微光”只在生产组件样例和对照图出现，不增加第三个用户工作模式。

`src/styles/tokens.css` 是唯一视觉参数源。页面排版可引用参数；普通控件的颜色、尺寸和状态由自己的组件决定。

### 音乐颜色与旧作品

角色默认色为粉鼓、蓝贝斯、杏和弦、薄荷旋律、紫氛围、浅青其他。用户已有的轨道颜色不被重写：`music-palette.js` 在显示层推导低饱和表面、深色文字和清楚边缘。旧作品可以继续显示不同的自选色；主题切换不保存音乐修改。

颜色之外继续使用文字、轮廓和状态标记。去掉阴影仍能认出控件和选择。渐变只作微弱固定表面，不做大面积模糊、鼠标追光、纹理或环境背景。

## 03 组件职责

| 家族 | 变体与规则 | 主要实现 |
|---|---|---|
| Button／IconButton | primary、secondary、quiet、danger；normal、small、icon；pressed/busy/disabled有实际语义 | ui/components.js、styles/components.css |
| Navigation／TaskChoice | 工作区位置与任务选择各有语义；焦点立即可见 | components.js、tool-panel.js |
| Field／Select／Slider | 标签、单位、边界、错误、默认值；数字输入与滑杆仍用原命令 | components.js、components.css |
| MusicTile／TimelineClip | 素材、组合、托盘、手中预览、落点和成品保留名称、轮廓与时长；画板跨度真实 | music-block.js、music-palette.js、arrange.js |
| TrackHeader／ChannelStrip | 名称、静音、只听、音量共享数据；混音密度可不同 | components.js、mix.js |
| ToolPanel／CandidatePanel | 当前对象、范围、输入、方案、采用、过期、草稿；数据仍由原控制器管理 | tool-panel.js、creation.js、composer.js |
| Notice／SaveStatus | 缺输入、过期、失败和保存不可用持久可见；短提示作补充 | messages.zh-CN.js、原保存控制器 |

小试听按钮在素材、声音和方案区域使用同一个small变体。布局文件不再改变其字体、点击区与主题。琴键、音符、时间尺和音乐块是音乐几何，不套普通按钮最小高度。

## 04 磁贴状态与准确操作

静止：上沿微光、浅底边和短投影；悬停只改表面。拿起：原件留在架上，独立预览跟手，文字和音符轮廓相同。落点：真实小节数、轨道、冲突原因。提交：原操作立即生效，一次撤销；之后可有100ms边缘提示。取消：Esc、失焦、换作品或无效外部drop进入统一清理。

“磁吸”表示时间网格与合法落点反馈。光标不会被拉走；不让弹簧、缓动或惯性决定音乐时间。点击放置与拖放共用PlacementPlan。示例作品必须明确新建，不能变成覆盖原稿的普通拖放。

## 05 微交互白名单

| 场景 | 允许 | 禁止 |
|---|---|---|
| 悬停 | 0—80ms颜色、边缘、浅表面变化 | 卡片平移、自动发声、周期动画 |
| 按下／焦点 | 即时；内阴影或颜色变化 | 缩字、跳位、等待动画 |
| 拖动／改长度 | 精确跟随，几何transition=none | 惯性、弹簧、拖尾、延迟吸附 |
| 落定 | 先提交，100ms边缘状态，可关闭 | 回弹、飞入、自动试听 |
| 面板／工作区 | 最终布局立即就位，恢复现场 | 推走操作对象、交错入场、自动回曲首 |
| 播放 | 真正音频时间驱动播放头和正在发声音符 | 假均衡器、按节拍放大磁贴 |
| 计算与保存 | 实际忙碌状态和真实进度；无进度就不用百分比 | 假进度、固定等待、动画结束后提交 |

生产样式没有keyframes，不使用transition:all或backdrop-filter。减少动态同时遵循系统偏好与本机开关。关闭所有transition和animation时，绘音、播放、停止、放置都可以完成。

## 06 空间与滚动

中间是整体纵向滚动容器，音符画板负责内部二维浏览。左托盘、右工具和宽库有各自范围；边界继续可达。顶底控制栏不随内容漂移。

1440×900、1280×800、1100×700为桌面检验尺寸。窄窗口右工具可覆盖，左侧可收起。宽库在更小有效区域中改为纵向排列，保留导航和滚动。极短窗口解除侧栏头部粘性，避免固定头吞掉主要动作。等效200%视口测试与真正Chrome缩放分别记录。

右工具按“工具类型＋固定目标”保存自己的滚动。切音色、演奏再回去不会因固定标签造成偏移。素材库在相同查询和排序中记住卡片区与筛选区位置；改筛选可以回顶；浏览不修改作品。

## 07 右侧方案

准备阶段显示任务、目标、范围、必要来源与少数音乐决定。精细参数折叠。结果阶段把“用这版”作为主动作，“再来一组”作为次动作。原稿、当前轨、伴奏按明确范围试听。

中央投影是只读显示，不成为音符命中对象，不进入历史或自动保存。已有CandidateSession负责参数、目标和有效输入校验。换无关音轨音量仍可合并；改来源则失效并就地说明。

## 08 文案与格式

品牌“乐构”；整份内容“作品”；时间轴对象“音乐块”；现成材料“模板”，多轨材料“组合模板”。比较临时结果用“方案”，暂存条件用“草稿”。“做几版”只计算；“试听”只发声；“放入／用这版／替换”提交作品。

沿用原formatter：一基小节/拍、读得懂的和弦、居中/左/右、真实dB和音高。保留旧扩展名、ID、枚举、用户标题及原采样来源。不能通过改名暗示不存在的AI或风格转换功能。

## 09 新功能的加入方式

先登记对象、必要输入、状态、作用范围、取消和失败恢复，再复用组件。确有差异，新增命名变体并更新生产组合样例。禁止在页面尾部增加高优先级规则去盖住其他组件。

`components.html`直接调用生产模块，并包含真实生成准备／就绪、长中文、错误、音色与磁贴。验收使用 `npm test`、`npm run verify:engineering`。`npm run verify:release`保留目标Mac、真实来源存储、实际缩放和初次使用者未测状态；自动脚本不是AI子代理或真人观察。
