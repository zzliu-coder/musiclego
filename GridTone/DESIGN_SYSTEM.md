# 乐构 1.5 · UI、交互与动效规则

主题：轻触、拿起、落定。颜色区分声音，薄厚度提示可操作性；工作台保持稳定。

## 工作视图

- **编排**：全曲为主，上方编排、下方编辑当前乐句。适合组织结构和移动片段。
- **乐句**：音符画布为主，左侧选声音，下方保留全曲概览。适合写旋律、鼓点及精细编辑。
- 两个视图共用作品、选中乐句与播放上下文；切换不重新建立音频图、不重设播放起点。
- 两个视图分别记住编辑器高度。分隔条支持指针和方向键；放大/收起有明确入口。
- 窄屏把声音选择改为横向列表，时间轴自身滚动，播放和工作视图保持可达。

## 视觉基础

| 类别 | 规则 |
| --- | --- |
| 底面 | 清白或暖白，网格无高光、无厚阴影；不使用大面积彩色背景 |
| 字体 | macOS 系统字体 / PingFang SC，主操作 13–16px，辅助信息 10–12px |
| 色彩 | 旋律蓝 #2875f5，鼓点珊瑚 #f66570，贝斯薄荷 #34b995，和弦杏橙 #ee9552 |
| 层级 | 工作台 / 薄键帽 / 临时拿起；不叠加装饰性卡片 |
| 材质 | 按钮和音符轻微上沿高光、下沿暗边和接触阴影；音符始终保持真实时间边界 |
| 选中 | 深色边界、必要的操作柄、aria 状态；不通过把音符变成红色来表达选择 |
| 焦点 | 独立的蓝色外圈，键盘焦点与鼠标悬停各自可识别 |
| 旧作品 | 迁移旧版默认配色；保留用户自定义颜色、音符与参数，继续支持 .gridtone 工程 |

## 统一状态表

| 状态 | UI / 交互反馈 | 时间 |
| --- | --- | --- |
| 默认 | 轻薄表面、清楚的文字，主要声音内容用彩色 | 静止 |
| 悬停 | 表面略亮，展示可调整边缘；不移动网格 | 140ms |
| 按压 | 按钮下沉 1px、阴影收紧，操作立即执行 | 75ms |
| 选中 | 保留轨道色，边界和调整柄出现 | 140ms |
| 拿起 | 4px 移动阈值后进入拖动，原位留轮廓 | 即时 |
| 拖动 | 乐句紧随指针，目标轮廓吸附；音符按实际时间/音高移动 | 每帧合并更新，无缓动 |
| 有效目标 | 目标描边及小节说明；同一落点缓存验证结果 | 即时 |
| 无效目标 | 虚线错误边界和文字原因，不抖动 | 即时 |
| 放下 | 一次提交/一次撤销，阴影收回；几何位置立即准确落定 | 表面 140ms |
| 取消 | Esc、pointercancel、窗口失焦恢复原内容和原选择 | 即时，不产生撤销项 |
| Mute / Solo | 按下状态，未发声轨道降低视觉强度；名字和操作仍可读 | 声音即时，表面 140ms |
| 播放 | 指针跟随音频时钟；实际处理时序对应的原音符轻微提亮 | 连续，无弹性 |
| 面板切换 | 必要时短距离 4px 淡入；控件保持上下文 | 210ms |
| 不可用 | 禁用、降低强度，不响应按压和位移 | 静止 |
| 保存/导出 | 文字状态与 aria-live；导出期间禁用重复提交，失败可见 | 与真实任务进度一致 |
| 空内容 | 画布给出第一步提示，不占用可编辑空间 | 静止 |

## 操作契约

- 指针在音符右缘拉伸；按住 Shift 追加选择；框选可多选；按 Escape 放弃进行中的手势。
- 乐句的吸附轮廓与指针反馈分离。跨轨仅允许同类型轨道；目标空间不足不提交。
- 同一拖动落点不反复克隆验证整首作品；连续输入通过 requestAnimationFrame 合并。
- 编辑音符时不放大、倾斜或回弹。时值、音高、力度都有独立的精细控制。
- 音频调度独立于 UI 动画。视觉从播放时钟读取状态；绝不等待动画完成再播放。
- 音符高亮考虑琶音、律动及处理后时序。全曲中被静音、未选入试听范围的轨道不提亮。
- 正在播放的音符可以自然收尾，未来音符按修改后工程重排程；不是交叉淡入淡出音频引擎。
- 复制/粘贴/删除按焦点归属到乐句或音符，不混用两个选择集合。
- 弹层使用已有焦点管理和 Escape 关闭；从更多菜单切换视图会关闭弹层并解除背景 inert。
- 高级工具放在“更多工具”，包括连续小节、适配、缩放、精细编辑和创作辅助。

## 减少动态

系统 `prefers-reduced-motion` 或应用「外观与动效 → 减少动态效果」任一开启即停用位移动画、过渡和落定动画。保留选中边界、吸附轮廓、播放位置及状态文字，不隐藏操作结果。播放指针仍反映真实进度。

## 实现入口

- `src/styles/legou.css`：语义颜色、表面层级、状态、时长、响应式。
- `src/ui/motion.js`：拿起/落点/落定、面板过渡、播放高亮及减少动态。
- `src/ui/editor-gestures.js`：指针事务、阈值、提交、取消与键盘归属。
- `src/views/shell.js`、`piano-roll.js`：两个工作视图及数据驱动的音乐画布。
- `src/session.js`：各视图高度、选中内容、缩放及工作区偏好。

## 验收边界

浏览器实测不等于所有触屏设备或声卡表现。未声称硬件触觉反馈、固定帧率、端到端音频延迟或长时间重负载性能通过。当前没有“下一小节才执行”的新操作，因此不添加虚假的排队状态。
