# 声格 GridTone v1.3 · Prism

**一块可以写写画画的音乐画板，配上通透的乐器面板、可比较的声音与一按生成的和弦进行。**

## 打开

打开根目录的 `声格.html`。它与 `dist/index.html` 相同，包含全部代码、47个离线合成预设和71个模板，无需账户、安装运行依赖或访问CDN。请使用完整浏览器，不要在聊天软件的HTML预览器里运行。

网页首次显示四轨八小节的《玻璃小夜曲》。点击播放即可听。重要作品通过「导出 → 工程文件」下载 `.gridtone`。界面显示实际保存状态；保存失败时，请直接下载工程备份。

`验收报告.html` 包含实际截图、结果和限制。`docs/` 包含设计指纹、结构、配置说明、研究来源、测试证据与检查点。

## 三条最快的玩法

**写和弦：** 编排中打开一个旋律片段 →「和弦进行」→ 选走向与主音 → 试听 → 生成。默认新增独立片段；也能新建音轨或明确替换已有片段。全部生成普通音符，可以继续拖动、拆分或一次撤销。

**挑声音：** 片段中的「本轨音色」→ 按乐器角色筛选 → 用同一段旋律、和弦或低音比较 → 点击“使用”。“试听”保留当前作品。右侧键盘试听正在使用的声音。

**从模板开始：**「模板与素材」→ 选择鼓点、旋律、贝斯、和弦或整曲起点 → 先听候选 → 明确应用到哪里。四套新整曲均可逐轨拆开；旧版示例和旧模板保留。

## 本版内容

| 内容 | 数量与实际范围 |
|---|---|
| 外观 | 冰晶、暖珠两套同构皮肤；统一字体／字号／间距／圆角／组件／状态；减少透明度和动态；主要触屏按钮44px。 |
| 离线音色 | 47个：26个旧预设保留，新增21个（18个旋律音色、3个鼓声预设）。新增声音采用七个合成族与不同鼓声配置。 |
| 可选实录 | 6个VSCO CC0轻量多采样目录：立式钢琴、竖琴、马林巴、长笛、小提琴拨奏、钟琴。首次明确载入需要联网。 |
| 和弦进行 | 24组，12主音，原位／就近／开放三种排列，长音／四拍／分解／逐音铺开四种弹奏。 |
| 新模板 | 16鼓点、12旋律、8贝斯、24进行默认版、4整曲，共64个新增模板；含7个旧模板，共71个。 |
| 鼓组 | 内置5套配置（旧2套＋新3套），仍可导入自定义行与采样。 |
| 编辑与保存 | 保留点、拖、长音、框选、A′、共享片段、只听与混音；工程仍为v2，兼容v1导入。WAV／MIDI／工程导出。 |

“就近连接”是在固定音域内选择移动较小的和弦转位，只处理音高接近程度，尚未加入严格四部和声约束。旋律和贝斯模板附参考和声；套进任意进行后仍需按听感修改。

## 实录与联网边界

47个合成预设与所有模板可直接离线使用。六个实录音源在「真实采样」分组中明确标为首次联网载入。选择后才向 `raw.githubusercontent.com` 请求固定版本文件；应用不会上传工程或录音。

本轮核对了公开仓库、CC0许可证、SFZ音高映射与下载目录。当前执行环境不能下载外部音频二进制，**六个真实录音的成功联网下载没有在本环境得到验证**。测试采用明确标注的原创WAV夹具，验证下载后的解码、转换、安装、工程内嵌、干净运行实例重开与实际音频渲染；夹具是测试用原创声音，不在应用里伪装成已就绪的实录音色。

用户联网载入成功并使用后，已用声音随工程保存。轻量版采用24kHz单声道、多根音、单力度、最长6秒，无自动循环；不等同完整原库。网络失败或取消不会改作品，也不会安装残缺音源。

## 结构与配置

`assets.json`管理开发与发行共用的资源顺序。`styles/tokens.css`管理语义外观，`material.css`管理材质。`music/progressions.js`保存和声规则，`audio/instruments.js`注册新声音，`catalog/builtin.json`保存配置。新音色、鼓组和模板可通过`.gridtonepack`扩展。

文档：
- `docs/DESIGN_FINGERPRINT.md`：怎样保持设计统一、怎样换皮肤。
- `docs/ARCHITECTURE.md`：工程／工作区／试听／目录的关系及实际文件职责。
- `docs/CATALOG.md`：配置格式、扩展约束、模板与声音的适配范围。
- `docs/CONTENT_LIBRARY.md`：所有新增声音、进行和模板索引。
- `docs/SOURCES.md`与`THIRD_PARTY_NOTICES.md`：研究来源、授权、采用与排除的理由。

## 开发与测试

要求Node.js 20或以上。运行和核心测试无npm运行时依赖。

```bash
npm start                 # http://localhost:8000，本地源码入口
npm test                  # 核心逻辑测试
npm run build             # 从JSON生成数据，再构建单文件
npm run catalog:generate  # 重新生成prism.*模板；会覆盖该命名空间的自动模板
```

浏览器测试另需Python Playwright与Chromium：

```bash
python3 -m pip install playwright
python3 -m playwright install chromium
npm run test:e2e           # 构建并执行六套浏览器检查
# 已有浏览器可设置 CHROMIUM_PATH=/path/to/chromium
```

本轮最终验收记录以`docs/TEST_REPORT.md`和对应JSON为准。实际运行包括原生WebAudio、WAV导出、文件下载与新运行实例重开，不以“没有报错”代替声音非静音验证。

## 验证边界

浏览器回归用完整内联页面运行，以绕过本测试环境的导航限制。实体手机扬声器／触控手感、真实延迟、Safari／Firefox、麦克风权限、真实网页来源的IndexedDB刷新恢复仍未实测。移动截图和指针尺寸检查属于Chromium触屏模拟。

工程上限64轨、256小节与100,000原始音符是数据限制，不代表手机可实时承载全部负载。WAV最长3分钟音乐并附尾音；MIDI保存音符和时间，无法携带本应用的具体合成器、采样与混响声音。采样资源有体积限制，应及时下载工程备份。

本版未加入VST、完整SFZ/SF2播放器、自由连线模块、自动化曲线或多人协作。
