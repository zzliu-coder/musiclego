## 使用

应用包里的 `Legou_2_2_1.html` 或源码里的 `dist/index.html` 均为完整离线应用，用桌面Chrome打开。源码根目录的 `index.html` 是开发入口，需要旁边的src文件。

```sh
npm start
# 在Chrome中打开服务器打印的地址。固定地址与端口，本机存档才保持同一来源。
```

运行和构建无需安装npm依赖。重要作品仍请主动下载 `.gridtone` 备份。

## 这轮补齐的五组内容

1. **时间编辑**：清除范围保留时间与有意休止；删除时间全轨前移。残段保持一块精确长度内容，避免4+2+1机械切割长音。未相交音符不新增起音。共享其他实例、和声、保留项、循环和撤销分别有测试。
2. **模板集合**：顶部“音乐模板”进入大库；全部/本次待用/收藏/最近/正在用都可用，旧集合只迁移一次，5份旧示例有独立新建入口。没有常驻窄托盘。
3. **声音层级**：从本轨音色进入唯一选择器；“调整当前声音”只显示本轨参数。“声音资源与导入”统一录音、导入、音源包和鼓组管理，深层不重复出现整套声音目录。
4. **批量放置**：单块音乐加入批量，选择接着放/一起放。计划面板可改顺序、起始小节、各项已有/新建音轨与音高处理；显示真实范围与投影。先“试听整组”或“连同作品听”，再“确认放入”。
5. **原能力回归**：原生单块拖放、鼠标/点击取消、固定音高尺、音域浏览、生成、预听、混音、导出及两套皮肤继续保留。

**批量与单块的区别**：单块合法拖放直接放入；批量拖放先固定计划位置，再明确确认，防止多轨被意外写入。取消、Esc和失焦恢复浏览现场；变动相关音乐后需要重新检查计划。只改其他轨道的无关设置，不会被采用候选覆盖。

## 文件兼容性

本版继续使用工程结构v3，并将音乐块允许长度扩为1—16个完整小节。旧作品可以导入本版；如果新作品含3/5/6/7等旧版不接受的块长，需要使用2.2.1或更新版本打开。旧2.2验证器会拒绝这些长度，不能宣称双向兼容。WAV/MIDI导出不依赖该块长集合。
