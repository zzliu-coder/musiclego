# 乐构 1.6 · 模板优先创作

彩色轻磨砂键帽的音乐工作台。编排视图组织全曲，乐句视图专注写音符；两个视图共享音乐与播放状态。UI、交互和动效遵循“轻触、拿起、落定”，详见 `DESIGN_SYSTEM.md`。

## 打开

双击 `乐构.html`，使用完整浏览器打开。它与 `dist/index.html` 相同，包含全部运行代码、47 个离线合成预设和 71 个模板，无账户、无 CDN、无运行时安装依赖。

开发预览：`npm start`。重新构建离线版：`npm run build`。核心测试：`npm test`。

顶部文件夹进入「我的作品」：每份作品独立保存，可切换、另存、下载和删除；每作品每隔至少 30 秒记录一个恢复点，最多 10 个。跨标签页发生冲突会拒绝覆盖，并提示另存或载入最新版本。不同浏览器/网页地址的本机存储独立，迁移作品请用「导出 → 乐构工程」。

## 编排与编辑

- 编排视图单击片段，在下方编辑；乐句视图使用上方大画布。双击片段放大。拖动中间分隔线调整高度，也可用方向键调整分隔线。
- Shift 多选片段；拖动整体移动；Alt 拖动生成独立副本。同类型音轨之间可以移动，使用目标音轨音色。
- 片段菜单支持普通复制、独立复制、重复引用、解除共享和删除。链接标记表示修改会同步到多个引用。
- 时间尺单击定位，拖动选择循环段。停止一次回到播放起点，再按一次清除循环选区并回曲首。
- 网格可选 1/8、1/16、1/32、三连音或自由时间。连续多小节和单小节模式可切换。
- B 画笔、V 选择、E 橡皮、H 浏览。和弦画笔支持大小三和弦、七和弦、挂留等类型。
- 拖音符移动、拖右边改长度、Shift 框选追加。Esc 取消当前手势，不产生撤销记录。
- 方向键移动所选音符；Alt + 左右按 1 tick 微调；Shift + 上下移动八度。
- Ctrl/⌘ + 滚轮围绕指针缩放时间；再按 Shift 改为音高行高缩放。浏览模式可以平移画布。
- 「精细编辑」可调整微时移、力度、音高与时长，先试听前后差异，再一次性应用。
- 力度区域：有选择时只改所选音符；没有选择时修改当前吸附格内的音符。
- 「更多工具」包含和弦进行、参考调性、律动、音符变换和片段管理。参考调性不自动改变已有音符。

## 边听边改

Space 播放/暂停；表单和按钮聚焦时保留原生键盘行为。音符画布内可用 ⌘/Ctrl A/C/V/Z；编排片段有独立的复制、粘贴、删除和方向键操作。

Solo 是临时试听，Mute 保存到作品。音量、声像和 Solo/Mute 更新不重编译乐谱。修改 BPM、撤销和普通音符编辑保持播放；正在响的音符自然收尾，未来事件重新排程。资源或轨道结构变化仍可能重建音频图。

音色与模板的候选试听不修改作品；结束试听恢复此前的范围、位置与播放状态。整首模板会保存当前作品并新建一份，可从「我的作品」切回；单片段模板与配套模板的应用可一次撤销。

## 导出

- 乐构工程：所有音符、设置与自定义音源，供继续编辑。
- MIDI：音符、速度与处理后的乐谱；不携带合成器音色或音频效果。
- WAV：44.1 kHz / 16-bit 立体声，包含效果及尾音。

默认导出全曲，尊重作品静音，忽略临时 Solo。也可选择当前片段或当前试听范围。

## 本轮新增

- 顶部文件夹管理多份作品。v1 / v2 工程自动迁移为 v3，原始文件保留。
- 画布常驻「模板」「和弦进行」「创作辅助」入口；编排区也有模板入口。
- 8 套配套模板，每套带和弦、鼓、贝斯、示范旋律和空白旋律轨。可试听整套或连同现有伴奏试听。
- 创作辅助支持 4 / 8 小节单声部生成，最多 3 个不同候选；可保留音高、节奏、全部或一段范围中的音符与休止。
- 可指定 / 复核显式和弦来源；来源变动会显示待更新提示，保留已经生成的普通音符。
- 鼓型变化、依据和弦 / 底鼓生成贝斯、伴奏承托 / 呼应 / 加强、整组生成。
- 回答句、只改结尾、8 / 16 小节编排与可预听的混音建议。
- 16 小节读写一致；精确减半 / 加倍 / 拆分支持小数 ticks，编辑时间轴随歌曲长度横向滚动。

## 开发与验证

运行开发服务器推荐固定同一地址，以保持浏览器本机存储连续。

```sh
npm ci
npx playwright install chromium
npm start
npm run verify
npm run verify:soak
npm run verify:release
```

已装 Google Chrome 的机器可用 `BROWSER_CHANNEL=chrome npm run verify`。离线运行 HTML 无需安装开发依赖；首次准备测试浏览器和 npm 依赖需要网络。

当前工程证据见 [验收记录](docs/implementation/acceptance.json)、[统一验证](docs/implementation/evidence/verification.json) 和 [实施合同](docs/implementation/CONTRACTS.md)。历史 1.5 报告不计入当前通过数量。

工程自动检查与人工听感分别记录。本轮提供可运行的工程候选版；人工听感未评审时，严格的 `verify:release` 会返回非零并列出待验收项。**用户已将小屏 / 触屏体验留到后续专题**；本轮视觉验收聚焦桌面 1280 / 1440。

容量：64 轨、256 小节、100,000 音符、自定义音源约 24 MB；WAV 每次最多 3 分钟、20,000 音符；MIDI 最多 15 条旋律轨。结构上限不等于实时负载保证。参考和弦必须覆盖目标实例；规则生成不会自动猜测缺失的和声。

原 `声格.html` 保留为兼容入口；工程扩展名和本机存储键继续沿用 GridTone，避免旧作品丢失。

外部真实采样仍按明确的下载按钮获取；内置合成预设离线可用。版权与来源保留在 `LICENSE` 和 `THIRD_PARTY_NOTICES.md`。
